# Brain OS - CPU Scheduling Simulator

## Overview

Brain OS is a Python-based CPU scheduling simulator.
It demonstrates CPU scheduling algorithms and calculates basic process performance metrics.

## Algorithms

- First Come, First Served (FCFS)
- Priority Scheduling
- Round Robin
- Shortest Job First (SJF) 

## Metrics

- Completion Time
- Waiting Time
- Turnaround Time
- Average Waiting Time
- Average Turnaround Time

## Requirements

- Python
- No external packages required

## How to Run

1. Open the Brain-OS folder in VS Code.
2. Open Terminal > New Terminal.
3. Run `python main.py`.
4. Choose a scheduling algorithm from the menu.
